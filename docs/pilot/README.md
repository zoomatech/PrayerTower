# Pilot onboarding kit

Everything to invite the 10 pilot members, get them installed, and hear back from them. Work through [PILOT_LAUNCH_CHECKLIST.md](../PILOT_LAUNCH_CHECKLIST.md) first.

| File | Use it for |
|---|---|
| [INVITE_EMAIL.md](INVITE_EMAIL.md) | The invitation, a reminder for anyone who hasn't joined after 3 days, and a thank-you at the end |
| [TESTER_INSTRUCTIONS.md](TESTER_INSTRUCTIONS.md) | The page testers read: installing on iPhone, signing in, what to try each week, and how to report a problem |
| [FEEDBACK_SURVEY.md](FEEDBACK_SURVEY.md) | The end-of-pilot survey, ready to paste into Google Forms or Microsoft Forms, plus a 3-question weekly check-in |

Words in `[BRACKETS]` are placeholders. Fill them in before sending. Each tester needs their own invite code (Admin → Invite codes, or its **Import from a spreadsheet (CSV)** button for the whole group).

The pilot is English only and iPhone only (iPad works too). The screenshots in `img/` were taken on 2026-10-28 from the current app, at iPhone size, with sample [Demo] content.

## Timeline (default, 4 weeks)

| When | What |
|---|---|
| Day 0 | Send the invite. TestFlight invitations go out at the same time ([TESTFLIGHT_EAS_GUIDE.md](../TESTFLIGHT_EAS_GUIDE.md) §7). |
| Day 3 | Send the reminder to anyone who hasn't signed in (Admin → Pilot metrics shows active pray-ers). |
| Weeks 1 to 4 | Send the weekly check-in every Friday. Read in-app feedback (Admin → Feedback) twice a week. |
| Day 28 | Send the end-of-pilot survey with the thank-you. |
| Day 35 | Fill in [PILOT_RESULTS_TEMPLATE.md](../PILOT_RESULTS_TEMPLATE.md). |
