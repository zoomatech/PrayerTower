# What's New text for v1.0

Drafted 2026-10-28 for Steve to edit. Character counts include spaces and line breaks.

## App Store

Apple's "What's New in This Version" field "isn't available for the first version" of an app. It is limited to 4,000 characters ([Apple, Platform version information](https://developer.apple.com/help/app-store-connect/reference/app-information/platform-version-information)). So v1.0 ships with the Description and Promotional Text from [STORE_LISTING.md](STORE_LISTING.md) and no What's New text.

**Ready for the first update (1.0.1 or 1.1)** (456/4,000). Use it if these features ship after the first store build. Remove any line that is already in 1.0.

```
Thank you for praying with us. In this version:
• "Pray now" widget: add it to your Home Screen to see the next request to pray for, and tap to open it.
• iPad and Mac: Messages shows your conversations side by side, and the feed uses the wider screen.
• Keyboard shortcuts on iPad and Mac: ⌘N for a new request, ⌘1 to ⌘5 to switch tabs.
• Choose which alerts you get and set quiet hours.
• Fixes: posts written offline now appear as soon as they are sent.
```
